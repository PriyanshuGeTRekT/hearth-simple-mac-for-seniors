Hearth A calm, simple home for the Mac.

Big buttons for the people they call, the apps they use and the sites they visit. Reminders read aloud, a Help button with scam warnings, and caregiver settings behind a PIN. Assistive Access, for the Mac.

Home

Big buttons. The people they love.

One click starts a FaceTime video call with family. The other buttons open the apps and websites they actually use, and nothing else.

  • Three text sizes and light, dark or high-contrast colours.
  • Fits everything on one screen, no scrolling to discover.
  • Today’s reminders at the top, the next one marked.

Reminders

Never miss a tablet or an appointment.

At the right time a big message appears and is read aloud, with two buttons: I’ve done it, or remind me in 10 minutes.

  • Daily or on chosen weekdays.
  • Won’t show yesterday’s reminder after the Mac was asleep all night.
  • Two at once queue up politely.

Help

One button for help, with scam warnings.

“I need help” calls the main helper by video or phone, shows their number in large print, and reminds them how phone scams work.

  • Nobody from Apple, Microsoft or the bank phones about a computer problem.
  • Never let a stranger take control of this computer.
  • If in doubt, call family first.

Always one click home

Home and Help float above every app.

Lost inside Safari or Mail? A small Home and Help bar stays on top of every window. Home hides the other apps (it never quits them), so nothing is lost.

  • Optional strict mode: only the apps on the home screen can come to the front.
  • Password prompts and system alerts are never blocked.
  • Quitting Hearth needs the caregiver PIN.

Caregiver

Set it up once, from your own Mac.

People, buttons, reminders, text size and a PIN in one settings window. Prepare it on your own Mac, save a setup file and send it over.

  • The PIN never travels in the setup file.
  • Every entry is checked on import: unsafe links are dropped and reported.
  • Open at login, fill the screen, strict mode.

Up and running in a minute.

Requires macOS 14 or later on a Mac with Apple silicon.

  1. Download

    Download Hearth.zip, unzip it and drag Hearth.app into your Applications folder.

    Or install it with Homebrew:

    brew install --cask priyanshugetrekt/hearth/hearth

    Run the brew tap command shown at the top of the page first.

  2. Open Anyway

    Hearth is not notarized by Apple, so macOS blocks the first launch. Open System Settings › Privacy & Security, scroll down and click Open Anyway next to Hearth.

    You only need to do this once.

  3. Get started

    The first launch opens the caregiver setup. Add people, buttons and reminders, set a PIN, then press Finish setup.

Prefer to build it yourself? Build from source with just the Command Line Tools.

Questions and answers.

Is there Assistive Access for Mac?

Apple’s Assistive Access is only on iPhone and iPad. Hearth brings the same idea to the Mac: a simplified home screen with big buttons that a family member sets up.

How do I make a Mac easier for an elderly parent?

Create a standard user account for them, install Hearth, add the people they call, the apps they use and their reminders, set a PIN and turn on Open at login. Hearth then fills the screen with big buttons.

Can my parent video call me with one click?

Yes. Each person gets a big button that starts a FaceTime video call. FaceTime must be signed in on that Mac.

Does Hearth stop scams?

It helps: the Help screen explains the usual phone scams, and strict mode keeps unknown apps from coming to the front. For a shield against remote-control scam apps, pair it with Warden.

Can I set it up remotely?

Prepare the setup on your own Mac, save a setup file and send it. On their Mac choose Use a setup file. The PIN is never included.

Why does macOS say Hearth cannot be opened?

Hearth is not notarized by Apple, so macOS blocks the first launch. Open System Settings › Privacy & Security, scroll down and click Open Anyway next to Hearth. You only need to do this once.

Is Hearth free?

Yes. Hearth is free and open source under the MIT License, with no account, analytics or network requests.
